# Math

Numeric functions and constants.

## Basics

| Function | Type | Description |
|---|---|---|
| `abs x` | Num → Num | Absolute value |
| `max a b` / `min a b` | Num → Num → Num | Maximum / minimum |
| `sqrt x` | Num → Float | Square root |
| `floor x` / `ceil x` / `round x` | Num → Float | Rounding |
| `exp x` | Num → Float | e^x |
| `log x` / `log2 x` / `log10 x` | Num → Float | Logarithms |

## Trigonometry

| Function | Description |
|---|---|
| `sin x` | Sine (radians) |
| `cos x` | Cosine |
| `tan x` | Tangent |

## Conversion

**`toFloat : Int -> Float`**

Converts an Int to a Float.

**`toInt : Float -> Int`**

Converts a Float to an Int (truncation).
